CHAPTER I
INTRODUCTION
Background and Rationale of the Study
Typing is an essential digital skill required in academic, communication, and professional settings. In today’s digital era, information technology has significantly shaped how people study, work, and interact. Many tasks such as writing documents, conducting research, programming, and online communication rely on efficient computer use. The ability to type quickly and accurately improves productivity, minimizes errors, and allows users to complete tasks more effectively.
Despite its importance, many students and beginners still experience low typing speed and accuracy due to limited practice and lack of effective training tools. Traditional typing tutor applications often rely on repetitive exercises, which may lead to boredom and reduced motivation among users. As a result, learners may not practice consistently, which negatively affects their ability to improve their typing skills.
Game-based learning has been introduced as an alternative approach to address these challenges. By incorporating interactive elements such as scoring systems, time-based tasks, and progressive difficulty, gamification can increase user motivation and encourage continuous practice. Research findings in the project support that gamification enhances engagement and helps learners develop skills through repeated and interactive experiences.
The proposed system, Type Tiles, is a standalone desktop typing application that utilizes a falling tile mechanic. In this setup, words or characters fall from the top of the screen, and users are required to type them correctly before they reach the bottom. This approach is designed to improve typing speed, accuracy, reaction time, and hand-eye coordination through continuous and time-pressured interaction.

General Objective
The main objective of this study is to design and develop Type Tiles, a gamified standalone typing application that improves typing speed, accuracy, and reaction time through falling tile mechanics and progressive difficulty levels.
Specific Objectives:
1. To design a desktop-based graphical user interface that supports falling tile typing gameplay and multiplayer lobby navigation.
2.  To develop a typing system with difficulty levels, scoring, and life/health mechanics where users input characters before tiles reach the bottom.
3.  To develop a multiplayer room code system that allows an instructor to generate a unique session code, enabling students to join a synchronized lobby and compete in real-time.
4.  To implement real-time performance metrics (Words Per Minute, accuracy rate, and error rate) for user feedback during single-player and multiplayer sessions.
5.  To evaluate the system based on usability, functionality, and effectiveness in improving typing skills and classroom engagement.

Definition of Terms
To ensure clear and thorough understanding of the concepts discussed, the key terms below are defined based on their use and context within this study:
Accuracy Rate – The percentage of typed words that are accurate and used to measure the accuracy of a user’s typing performance.
Avatar Selection – A feature that allows users to choose or customize user profile characters.
Difficulty Levels – A gameplay mode settings where (Easy, Normal, Hard) that control the speed and complexity of falling tiles.
Error Rate – The percentage of incorrect words entered by the user during the game.
Falling Tile Mechanics – A gameplay feature where words continuously fall from the top of the screen. The users must type them correctly before falling words reach the bottom.
Gamification – A design approach that incorporates game elements such as scoring, levels, and performance feedback to make the system more engaging and encourage continued user interaction.
Hand-Eye Coordination – The ability to coordinate what the user sees on the screen with their hand movements while typing.
Life Bar / Health System – A visual indicator that reflects the users remaining chances, which reduces after errors or missed tiles.
Local Multiplayer – A feature that allows multiple players to participate in the game through a shared room code using different devices connected to the same local network (LAN).
Performance Tracking – A system that records and evaluates user progress such as typing speed, accuracy, and gameplay results.

CHAPTER III
METHODOLOGY
Research Design
This study utilizes the Developmental Research Design as its primary methodological framework to guide the systematic planning, architectural development, and iterative evaluation of Type Tiles: A Gamified Standalone Typing Application Using Falling Tile Mechanics for Skill Development. A developmental framework is pivotal for this study as it inherently focuses on the creation, testing, and implementation of technical software solutions and instructional tools designed to address real-world challenges.
To operationalize the software development phases of this research, the study adopts the Agile Development Methodology. Under this iterative approach, the product lifecycle involves continuous cycles of planning, designing, developing, testing, and evaluating, allowing for flexible adjustments and repeated revisions based on ongoing feedback. This methodology enables the researchers to systematically and adaptively build the three-actor interfaces—categorized as student, teacher, and admin—while continuously configuring and testing the Local Area Network (LAN) multiplayer environments required for classroom implementation. Furthermore, this dynamic workflow allows the team to incrementally develop the inclusive, multi-category application architecture, ensuring that both the standard alphanumeric typing logic and the specialized translation module—which renders stenographic shorthand strings for target users to decipher into standard English string outputs—are refined and optimized through continuous testing prior to final deployment.

The proposed system, Type Tiles: A Gamified Standalone Typing Application Using Falling Tile Mechanics for Skill Development, follows a Three-Tier Architecture consisting of the Presentation Layer, Application Layer, and Database Layer. This architecture was selected because it provides an organized structure that separates the user interface, system logic, and data management processes, making the system easier to develop, maintain, and expand in the future. The architecture supports both standalone offline gameplay and local multiplayer functionality while maintaining efficient processing of real-time typing interactions and performance tracking.

The system utilizes a desktop-based front-end developed using TypeScript and Phaser.js for interactive game rendering and gameplay mechanics. The application layer is handled through Node.js, which manages multiplayer sessions, authentication, scoring systems, and communication between the application and the database.
